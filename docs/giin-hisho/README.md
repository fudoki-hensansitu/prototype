# giin-hisho

議員の AI 秘書を、個人 AI エージェント（Muse など）の形で見せる試作。左のサイドナビに会話と仕事、真ん中にその仕事に合った画面（区政報告の紙面、「検討します」答弁の追跡表、今週の動き）、下に常にチャット欄を置き、送ると見ていた画面の続きとして会話に引き継ぐ。

確かめたいのは、議員が「自分の事務所に秘書がいる」と感じるか、どの仕事の画面に一番反応するか。

- 公開: https://prototype.fudoki.dev/giin-hisho
- 実装: [`giin-hisho/index.html`](../../giin-hisho/index.html)。単一の HTML。議員名・数字・出来事はすべて架空で、AI にはつながっていない（チャットは決め打ちの返答）
- 画面上の「ダミーです」の表示は、本人の指示で出していない
